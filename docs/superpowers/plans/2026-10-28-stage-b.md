# Stage B (final-b) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans. Steps use `- [ ]`.

**Goal:** Server-side XP (ledger), tiers with sub-levels, weekly quests and the tier-up moment; merge only if every test passes.

**Architecture:** Pure maths in `supabase/functions/_shared/xp.ts` (formula, caps, slots, tiers, quests, season clock). An `xp_ledger` table whose unique constraints make double counting impossible (one row per source+ref, run slots 1 and 2 per UTC day, one row per proof). `season` GET awards what the verified data earns (runs, shares, invites, quests, today's stake if the cron hasn't) and returns `xp`, `tier`, `quests`. A new `xp-cron` (pg_cron 00:10 UTC, both networks, cron secret) snapshots each signed-in user's active stake and awards daily stake XP. Tier skins are unlocked as `source='tier'` rows; Stage A milestone unlocks stay.

**Spec:** the owner's brief, Stage B section; `design/Kickback Prototype.html`.

## Global Constraints

- XP never trusted from the client; every award is a ledger row derived from verified data or an RPC snapshot.
- Daily stake XP: `min(2000, round(50 * sqrt(active staked NIM)))`, once per UTC day.
- Run your plan: +200 per run with ≥1 verified tx and run total ≥ the user's `min_ready_luna`; max 2 per UTC day.
- Share with someone: +100 per run with a verified send; max 2 per UTC day. Invite: +500 per credited invitee. Quest: +300 each, once per week.
- Season 1 ends 2026-11-30 23:59 UTC. Tiers Spark 0, Kick 1,000, Bounce 3,000, Rally 8,000, Surge 20,000, Legend 50,000; 3 sub-levels (equal thirds; Legend 50k / 75k / 100k).
- Weekly reset Monday 00:00 UTC. Quests: "Run your plan 3 times", "Add someone to your plan", "Keep your stake all week" (7 daily snapshots).
- XP resets per season; unlocks stay. Mainnet/testnet separate. Paused in preview and dry run.

## Review Focus

1. Re-posting the same run or share (same run_id): XP once (unique proof).
2. A third qualifying run on one UTC day: no XP (slot constraint).
3. Run whose total is below the minimum (e.g. 0.05 NIM with min 0.10): no run XP.
4. Season GET called many times in a day before/after the cron: daily stake XP exactly once.
5. After Nov 30 23:59 UTC: no new XP; ended state shows final tier.
